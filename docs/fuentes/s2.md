# Sentinel-2

| Campo | Valor |
| :-- | :-- |
| Endpoint | Statistical API de CDSE (`sh.dataspace.copernicus.eu/api/v1/statistics`); sin credenciales, ventanas COG de Earth Search |
| Autenticación | `CDSE_CLIENT_ID` + `CDSE_CLIENT_SECRET` (OAuth client credentials); ninguna para Earth Search |
| Producto / versión | sentinel-2-l2a (B8A, B05, SCL) |
| Resolución | 20 m |
| Límites de uso | Cuota mensual de unidades de procesamiento de la cuenta CDSE; en Earth Search, 3 lecturas por rango HTTP por escena y ventana ≤ 2 millones de píxeles |
| Ventana aplicada | máx(2015-06-23, hoy − 10 años), acotada a la primera y última escena del AOI |
| Rango real obtenido | Año 2024 completo por COG en `parcela_poligono`: 73 fechas con escena, 48 con NDRE válido (media 0,28; rango 0,16–0,45), 6 min. Statistical API pendiente de credenciales |
| Caché | Cada año cerrado (ambas rutas): la ventana de 10 años solo se calcula una vez |
| Alternativa | openEO de CDSE con `aggregate_spatial` |

Producto y variables de origen: sentinel-2-l2a; B8A, B05, SCL y dataMask.

OAuth client credentials. La API calcula NDRE y percentiles por día sobre el polígono o una caja de aproximadamente 40 × 40 m para un punto. Excluye SCL 3, 8, 9, 10 y 11. El catálogo público de CDSE acota la primera y última escena L2A del AOI antes de consultar estadísticas por año. openEO es una alternativa. Rango pendiente de consulta autenticada.

[Referencia oficial](https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Statistical.html)

Para enero de 2025, el catálogo público registró escenas locales entre el 5 y el 30 de enero. La vía Statistical API sigue pendiente de autenticación.

Sin credenciales CDSE se usan ventanas COG de [Earth Search](https://github.com/Element84/earth-search), con valores de reflectancia según los metadatos del activo. Se elige la escena con más píxeles utilizables por día, sin mosaico entre teselas. En el polígono de ejemplo hubo seis fechas con escenas en enero de 2025 y tres con NDRE válido. El método se marca en el producto y la bandera de cada fila.
