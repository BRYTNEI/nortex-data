# IMERG

Producto y variables de origen: GPM_3IMERGDF y GPM_3IMERGDL v07; precipitation.

CMR devuelve los enlaces OPeNDAP. Se solicita un píxel de 0.1° por día, se usa Late después de Final y se conservan banderas de procedencia. Se pueden calcular extremos sobre cualquier intervalo y acumulados de meses completos. Giovanni es una alternativa para promedios espaciales. Rango de salida pendiente de consulta autenticada.
