# SMAP

Producto y variables de origen: SPL4SMGP.008; Geophysical_Data_sm_surface y Geophysical_Data_sm_rootzone.

El catálogo AppEEARS confirma 31 de marzo de 2015 como inicio y capas a 9 km. Cada bloque anual usa la API de punto. La salida diaria promedia las muestras de tres horas y cuenta muestras válidas. El catálogo consultado no expone una bandera QC dedicada. El polígono usa su punto representativo; Harmony admite recortes de área. Rango de salida pendiente de consulta autenticada.
